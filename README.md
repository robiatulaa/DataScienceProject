## 📂 Repository Structure & Projects

Below is a brief overview of the projects included in this repository:

### 1. `amazon_recommender_system`

A recommendation system project based on Amazon product data. Focuses on building and evaluating recommender models.

### 2. `arxiv-nlp-analysis`

Natural Language Processing (NLP) analysis on arXiv paper abstracts, including text preprocessing, topic exploration, and insights extraction.

### 3. `DatabaseManagementQueries`

A collection of SQL queries demonstrating database management, data retrieval, and analytical querying skills.

### 4. `fromWesteros_toTwitter`

A text analysis project connecting fictional data (Game of Thrones) with social media (Twitter) insights.

### 5. `gmap_reviews_text_mining`

Text mining and sentiment analysis on Google Maps reviews to extract customer insights.

### 6. `jabodetabek_house_price`

An exploratory data analysis and modeling project focused on house price data in the Jabodetabek area.

### 7. `property_data_transformation`

Data transformation and preprocessing project for property-related datasets.

### 8. `retail_data_cleaning`

Data cleaning pipeline for retail transaction data, focusing on data quality and consistency.

### 9. `sales_performance_measurement`

Sales performance analysis using KPIs and metrics to evaluate business performance.

### 10. `simple_card_game`

A simple programming and logic project simulating a card game.

### 11. `sims`

A simulation-based project focusing on scoring and analytical visualization.
